    How it works

    The bridge

    The bridge connects the phone to ROS 2. If you can read this, it runs.

    Connect the phone

    By USB at the desk, or by Wi-Fi on the table.

    1. On the phone: Settings › About phone › tap “Build number” seven times.
    2. Settings › Developer options › turn on “USB debugging”.
    3. Plug the phone into this PC and allow it on the phone.
    4. On this PC, in the atl-phone folder:
      ./scripts/usb.sh
    5. The face opens on the phone: tap ▶.

    USB makes the page the phone's “localhost”: a secure page, so camera, microphone and motion work without certificates. The cable charges the phone too.

    Without HTTPS the face works, but camera, microphone and motion are blocked on Wi-Fi. Use USB, or start the bridge with a certificate: ./start.sh --cert DIR

    Once per phone: let it trust this PC

    Then, every time: the face

    1. Put the phone on the same Wi-Fi as this PC.
    2. Scan the code with the phone's camera, or type the address:
    1. The face opens on the phone: tap ▶.

    Phone check

    What can this phone do? The check tests each part once. You can skip it.

    2. On the phone: “Test everything”, allow camera, microphone and motion.
    3. Then “Send report to the PC”, and “Robot face →” to come back.

    Test it

    Each test goes through ROS 2, as a robot program would. Outputs: say what you saw. Senses: they tick by themselves.
